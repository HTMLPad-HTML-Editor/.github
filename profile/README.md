## First Look at HTMLPad

HTMLPad is for people who keep HTML they own and want one named code desk, not mixed notepad copies. It gives you an HTML editor, own pages, and a short path back to web files you already use. It does not replace the rest of your PC. It sits beside the browser and keeps the files close.

Work stays on pages you keep. Extra sites wait for their own title.
